# تبدیل اعداد به نمودار کندل‌استیک (OHLC)

ابزاری برای تبدیل یک دنباله ساده از اعداد به کندل‌های OHLC و نمایش آن‌ها به شکل نمودار کندل‌استیک واقعی (مشابه بازارهای مالی)، همراه با اندیکاتورهای تکنیکال اختیاری.

## نصب

```
pip install -r requirements.txt
```

## اجرا

```
python app.py
```

## نحوه کار

- اعداد را مستقیم در جعبه متن وارد کنید (با فاصله، کاما یا خط جدید از هم جدا کنید) یا از یک فایل CSV/Excel بارگذاری کنید.
- تعداد اعداد تشکیل‌دهنده هر کندل را انتخاب کنید (مثلاً ۴، ۵، ۶ و ...).
- هر گروه از اعداد به یک کندل تبدیل می‌شود:
  - **Open** = اولین عدد گروه
  - **High** = بیشترین عدد گروه
  - **Low** = کمترین عدد گروه
  - **Close** = آخرین عدد گروه
- در صورت نیاز، اندیکاتورهای Moving Average، Bollinger Bands، RSI و MACD را فعال کنید.
- خروجی OHLC را می‌توان به‌صورت فایل CSV ذخیره کرد.

## فایل‌ها

- `core.py` — منطق تبدیل اعداد به OHLC و خواندن ورودی از فایل/متن
- `indicators.py` — محاسبه اندیکاتورهای تکنیکال
- `app.py` — رابط گرافیکی (Tkinter + mplfinance)
